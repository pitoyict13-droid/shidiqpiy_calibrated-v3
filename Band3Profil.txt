//@version=6
// Bandz Po3 Profiler. Original implementation: HTF candles (3 lanes, FVG / VI, badges), C1/C2/C3/C4
// profiling with T-Spot, PSP, SMT on a 15m-1D ladder plus SSMT on 90m / 6H quarters, CISD, status bar,
// and 4-asset auto correlations (indices, metals, energy, bonds, FX majors/minors, BTC / ETH).
// + Signal panel, entry alerts (CISD / C3 / C4) and order entries (Entry / SL / TP1 / TP2).
// v4.7: CHART <-> DASHBOARD SYNC
//     - new input "Chart: hanya sequence live + order aktif" (poChartLiveOnly, default on).
//       On: the chart draws ONLY live sequences (T-Spot boxes of a live sequence) and ONLY active orders
//       (pending / open / runner). Finished sequences and closed orders are hidden, so the chart matches
//       the signal panel instead of showing stale "SELL C3 / TP1 ✓ / TP2 ✓" or a BUY runner of a dead sequence.
//     - new poActiveOrder(): returns the newest active order (status 0..2) from ANY sequence.
//     - signal panel: when the live sequence has no order but an OLD sequence still has an active order,
//       ACTION shows "HOLD BUY/SELL ... (status) · <live action>" and Order / Entry-SL / TP1-TP2 / Status
//       show that older order (marked "(seq lama)"), so the panel and the chart line up.
//     - off = old behaviour (full history on the chart, panel reads only the live sequence).
// v4.6: ENTRY NOW + ENTRY EXPIRY
//     - every order carries an expiry (PoTrade.expT) = the EARLIER of: "Pending expires (bars)" and the close of
//       the phase candle the entry belongs to (C3 entry dies when C3 closes, C4 entry when C4 closes).
//       A pending order past its expiry is cancelled and can no longer fill.
//     - signal panel: ACTION row shows "ENTRY NOW" (green / red highlight) with side, limit / market price and the
//       countdown while an entry is actionable (pending limit, or an entry taken within "ENTRY NOW window" bars)
//     - new panel row "Entry expires" (valid-until clock + countdown; before an order exists it shows the setup
//       deadline = end of the live C3 / C4 candle)
//     - chart: pending ENTRY label shows "exp HH:mm", the pending order lines extend towards the expiry,
//       alert texts include "valid until HH:mm"
// v4.5: REVIEW FIXES
//     - FIX A: C3 / C4 T-Spot signals and orders now require a LIVE sequence (rc.alive). Before, a failed
//       C3 (closed against the sequence) or a finished C4 could still fire a signal / order hours later
//       when price touched the old zone. The CISD signal also requires a live sequence.
//     - FIX A2: order state machine: a pending order whose sequence died / T-Spot died is cancelled
//       BEFORE it can fill (before, a near-edge limit could fill on the same bar it should be cancelled)
//     - FIX B: "phantom C2" filter. The expansion candle of a live sequence (its C3 / C4) used to qualify as a
//       C2 of the OPPOSITE side (it opens inside the old C2 and runs past its extreme). That phantom took over
//       the header / panel ("C2 MANIP" while C3 was running), could fire a false CISD and could kill a valid
//       C4. The newer side is now dropped when its C2 candle is the C3 / C4 candle of the still-live older side.
//       A real reversal appears once the old sequence has died (C3 closed against it).
//     - FIX C: the right edge of the live C3 / C4 T-Spot box uses the NY-anchored HTF close (poHtfSpan),
//       not time_close(tf) (exchange session clock)
//     - minor: SMT 4H lane now uses the same NY-anchored bucket as the HTF lanes (SMT lines on HTF candles
//       no longer disappear when the anchor differs from the exchange clock); variable "fill" renamed
//       (it shadowed a built-in name)
// v4.4: PARAMETER <-> C1-C4 (AMD) LOGIC RECONCILIATION
//     - "C2 must close inside C1" (poReqC2In) is now honoured by the sequence detector itself,
//       not only by the T-Spot / order filter; switching it off keeps reclaim-less sequences
//     - the T-Spot close-through kill (spot3Dead / spot4Dead) only runs on Easy and up, exactly as
//       the filter tooltip promises; "Open" no longer loses boxes / signals after a close through
//     - sequences can no longer stay alive forever when the profile lane is unavailable or switched
//       (their boxes used to stretch to the right edge and the panel kept reading them as live)
//     - "C3 / C4 on confirmed bar" tooltip corrected: it gates the signal as well as the order
//     - poTSpotMode "C2 open → wick %" is now phase-anchored: the C4 box is measured from the C3
//       open into the C3 wick (PoRec gained c3Open / c3Wick) instead of reusing the C2 leg, so the
//       C4 T-Spot no longer sits on top of the C3 box
// v4.3: SIGNAL PANEL REWRITE (per live sequence, calibrated with the C1-C4 phases)
//     - new ACTION row: NO TRADE / WAIT (MANIP, displacement, retrace) / BUY-SELL LIMIT / ACTIVE
//     - Phase row with direction + countdown; CISD / C3 T-Spot / C4 T-Spot rows read the LIVE sequence only
//     - Order / Entry-SL / TP1-TP2 / Status belong to the live sequence; if no order, Status says why
//     - old orders and old signals no longer look like current signals ("Last closed" row, dimmed)
//     - PoRec got sigC3T / sigC4T (signal time per sequence)
// v4.2: PHASE CANDLE TIMER
//     - live phase (C1 ACC / C2 MANIP / C3 DIST / C4 CONT) + countdown to close in the header,
//       on the live profile candle label and in the source-lane badge
//     - "Next:" schedule row in the header = when the following phases start
//     - fixed a compile error (two statements were glued on one line: poFireC4 / poNewCisdTrade)
// v4 (AMD calibration):
//     - T-Spot C3 / C4 signal needs displacement first: price must CLOSE out of the zone in the sequence
//       direction, then retrace back into it (no more instant signal on the first C3 / C4 bar)
//     - C3 entry only while the sequence is in C3 (no stale C3 entry once C4 started)
//     - C4 phase only if C3 closed with the sequence (failed distribution stops at C3)
//     - C2 must sweep C1 by a minimum % of the C1 range (no 1-tick manipulation)
//     - HTF candles on intraday charts are anchored to a fixed NY hour (default 18:00) so 90m / 6H quarters
//       and 4H candles are identical on futures, forex and crypto
//     - TP2 can target the C1 opposite extreme, TP1 default = C1 midpoint (distribution targets)
//     - PSP ignores doji candles
// v2: auto-asset library rewritten (crypto spot/perp, forex major + minor/cross, index futures + CFD,
//     commodities), self/duplicate asset guard, auto opens per asset class, conservative same-bar SL,
//     CISD signal only on confirmed bar close (no repaint).
// v3.1: phase names (C1 ACC / C2 MANIP / C3 DIST / C4 CONT) on candles + chart labels, phase tracker in the header,
//       CISD / C3 / C4 signal markers on the signal bar
// v3: order-entry calibration
//     - CISD order now follows the T-Spot strictness filter (Open/Easy/Medium/Hard/Max)
//     - CISD order can wait for the C2 close (C3 open) so SL / C2 range are final
//     - C3 / C4 orders only on a confirmed bar close (no intrabar repaint)
//     - max orders per sequence (default 1) so CISD / C3 / C4 do not stack 3x the same risk
//     - max risk % of price + min TP1 R filters, spread / slippage ticks added to entry and SL
//     - pending limits are cancelled when the sequence dies, the T-Spot dies, or price runs through SL
//     - Midpoint / Far edge limits can only fill from the bar AFTER the signal bar
//     - stats in the signal panel (closed, SL / BE / TP2, hit rates, net R) + capped candle markers
// v4.1 fix: countdown badge now uses the same NY-anchored bucket as the HTF candle cutter, so 6H / 12H
//           close times match the C1 -> C2 -> C3 -> C4 switch (no more stale 00:00 badge).

// ── Helpers shared by the asset layer ────────────────────────────────────────
poShort(string s) =>
    array<string> parts = str.split(s, ":")
    parts.get(parts.size() - 1)

    ticker.modify(ticker.inherit(syminfo.tickerid, sym), backadjustment = backadjustment.on)

    request.security(tkr, timeframe.period, [time, time_close, open, high, low, close], gaps = barmerge.gaps_on, lookahead = barmerge.lookahead_off, ignore_invalid_symbol = true)

// ── Auto correlation library v2 ──────────────────────────────────────────────
poHasAny(string s, array<string> keys) =>
    bool hit = false
    for k in keys
        if str.contains(s, k)
            hit := true
    hit

// Forex pair naming order: EUR > GBP > AUD > NZD > USD > CAD > CHF > JPY
poFxRank(string c) =>
    array<string> order = array.from("EUR", "GBP", "AUD", "NZD", "USD", "CAD", "CHF", "JPY")
    order.indexof(c)

// Pair "c1 vs c2" that RISES when c1 strengthens against c2.
// Returns [symbol, invert]; invert = true when the market pair is the opposite quote.
poFxPair(string c1, string c2) =>
    bool direct = poFxRank(c1) < poFxRank(c2)
    string nm = direct ? c1 + c2 : c2 + c1
    [syminfo.prefix + ":" + nm, not direct]

// Returns [a, b, c, invA, invB, invC, class]. Class: crypto / fx / com / idx / bond
poAutoSet() =>
    string r   = str.upper(syminfo.root)
    string t   = str.upper(syminfo.ticker)
    string ty  = syminfo.type
    string bc  = na(syminfo.basecurrency) ? "" : syminfo.basecurrency
    string qc  = na(syminfo.currency) ? "" : syminfo.currency
    bool   gxt  = poDivMode == "Triad (GXT)"
    bool   perp = str.endswith(t, ".P")
    bool   cash = ty != "stock" and ty != "fund" and ty != "dr"

    bool isCrypto = (ty == "crypto" or perp) and bc != ""
    bool isFx     = ty == "forex" and poFxRank(bc) >= 0 and poFxRank(qc) >= 0

    // index (futures micro/mini + CFD / cash)
    bool fNQ   = r == "NQ" or r == "MNQ" or (cash and poHasAny(t, array.from("NAS100", "US100", "USTEC", "NDX", "NASDAQ")))
    bool fES   = r == "ES" or r == "MES" or (cash and poHasAny(t, array.from("US500", "SPX", "SP500")))
    bool fYM   = r == "YM" or r == "MYM" or (cash and poHasAny(t, array.from("US30", "DJI", "DJ30", "WS30")))
    bool fRTY  = r == "RTY" or r == "M2K" or (cash and poHasAny(t, array.from("US2000", "RUT", "RUSSELL")))
    bool fDAX  = r == "FDAX" or r == "FDXM" or (cash and poHasAny(t, array.from("GER40", "DE40", "DAX", "GER30", "DE30")))
    bool fSX5E = r == "FESX" or (cash and poHasAny(t, array.from("EU50", "STOXX50", "SX5E", "ESTX50")))
    bool fFTSE = r == "Z" or (cash and poHasAny(t, array.from("UK100", "FTSE")))

    // commodities
    bool fGold = r == "GC" or r == "MGC" or (cash and poHasAny(t, array.from("XAUUSD", "GOLD")))
    bool fSilv = r == "SI" or r == "SIL" or (cash and poHasAny(t, array.from("XAGUSD", "SILVER")))
    bool fPlat = r == "PL" or (cash and poHasAny(t, array.from("XPTUSD", "PLATINUM")))
    bool fPall = r == "PA" or (cash and poHasAny(t, array.from("XPDUSD", "PALLADIUM")))
    bool fCopp = r == "HG" or (cash and poHasAny(t, array.from("COPPER", "XCUUSD")))
    bool fWti  = r == "CL" or r == "MCL" or (cash and poHasAny(t, array.from("USOIL", "WTI", "XTIUSD", "CRUDE")))
    bool fBrnt = r == "BRN" or (cash and poHasAny(t, array.from("UKOIL", "BRENT", "XBRUSD")))

    string a = ""
    string b = ""
    string c = ""
    bool ia = false
    bool ib = false
    bool ic = false
    string cls = ""

    if isCrypto
        // BTC -> ETH, SOL, XRP | ETH -> BTC, SOL, XRP | others -> BTC, ETH, SOL
        array<string> maj = array.from("BTC", "ETH", "SOL", "XRP")
        string px  = syminfo.prefix + ":"
        string sfx = perp ? ".P" : ""
        int cnt = 0
        for m in maj
            if m != bc and cnt < 3
                string s = px + m + qc + sfx
                if cnt == 0
                    a := s
                else if cnt == 1
                    b := s
                else
                    c := s
                cnt += 1
        cls := "crypto"
    else if ty == "futures" and (r == "BTC" or r == "MBT")
        a := "CME:ETH1!"
        cls := "crypto"
    else if ty == "futures" and (r == "ETH" or r == "MET")
        a := "CME:BTC1!"
        cls := "crypto"
    else if isFx
        if qc == "USD"
            // EURUSD, GBPUSD, AUDUSD, NZDUSD
            string x1 = bc == "EUR" ? "GBP" : bc == "GBP" ? "EUR" : bc == "AUD" ? "NZD" : bc == "NZD" ? "AUD" : "EUR"
            string x2 = bc == "EUR" or bc == "GBP" ? "CHF" : bc == "AUD" ? "EUR" : bc == "NZD" ? "GBP" : "GBP"
            [s1, i1] = poFxPair(x1, "USD")
            [s2, i2] = poFxPair(x2, "USD")
            a := s1

// Local-time offset (poTz) vs UTC for the current bar
int poTzOff = timestamp("UTC", year(time, poTz), month(time, poTz), dayofmonth(time, poTz), hour(time, poTz), minute(time, poTz), 0) - (time - time % 60000)

// Open / close of the HTF candle built from the same anchor bucket as the cutter.
// Falls back to time(tf) / time_close(tf) for 1D+ and non-intraday charts.
poHtfSpan(string tf, int bk) =>
    float sec = timeframe.in_seconds(tf)
    int o = na
    int c = na
    if poAnch and not na(sec) and sec < 86400 and not na(bk)
        o := int(poAnchorH * 3600000.0 + bk * sec * 1000.0) - poTzOff
        c := int(poAnchorH * 3600000.0 + (bk + 1) * sec * 1000.0) - poTzOff
    else
        o := time(tf)
        c := time_close(tf)
    [o, c]

poCountdown(string tf, int bk) =>
    [openT, closeT] = poHtfSpan(tf, bk)
    string res = ""
    if not na(closeT)
        int nowT = barstate.isrealtime ? timenow : math.min(timenow, na(time_close) ? timenow : time_close)
        int remMs = math.max(closeT - nowT, 0)
        int totalS = int(math.floor(remMs / 1000.0))
        int hrs = int(math.floor(totalS / 3600.0))
        int mins = int(math.floor((totalS % 3600) / 60.0))
        int secs = totalS % 60
        string mm = mins < 10 ? "0" + str.tostring(mins) : str.tostring(mins)
        string ss = secs < 10 ? "0" + str.tostring(secs) : str.tostring(secs)
        res := hrs > 0 ? str.tostring(hrs) + ":" + mm + ":" + ss : mm + ":" + ss
    res

        res := math.max(0.0, math.min(1.0, float(closeT - nowT) / float(closeT - openT)))
    res

poOpenCandle(PoLane lane) =>

poUpdateCandle(PoLane lane) =>
    int n = lane.cs.size()
    if n > 0
        PoCandle cd = lane.cs.get(n - 1)
        if high > cd.h
            cd.h := high
            cd.hiBar := bar_index
        if low < cd.l
            cd.l := low
            cd.loBar := bar_index
        cd.c := close
        for k = 0 to 3
            if poSOk.get(k)
                if cd.ok.get(k)
                    cd.ah.set(k, math.max(cd.ah.get(k), poSH.get(k)))
                    cd.al.set(k, math.min(cd.al.get(k), poSL.get(k)))
                    cd.ac.set(k, poSC.get(k))
                else
                    cd.ao.set(k, poSO.get(k))
                    cd.ah.set(k, poSH.get(k))
                    cd.al.set(k, poSL.get(k))
                    cd.ac.set(k, poSC.get(k))
                    cd.ok.set(k, true)
    lane

// ── PSP ──────────────────────────────────────────────────────────────────────
poPspFlag(PoCandle cd) =>
    int d = poDir(cd.o, cd.c)
    int valid = 0
    int differ = 0
    for k = 0 to 3
        if poAOn.get(k) and cd.ok.get(k)
            valid += 1
            int dk = poDir(cd.ao.get(k), cd.ac.get(k)) * (poAInv.get(k) ? -1 : 1)
            // v4: a doji (direction 0) on either side is not a divergence
            if dk != d and dk != 0 and d != 0
                differ += 1
    bool res = false
    if valid > 0
        res := poPspAll ? differ == valid : differ > 0
    res

// ── Po3 sequence ─────────────────────────────────────────────────────────────
poEvalSide(array<PoCandle> cs, int side) =>
    PoSeq res = PoSeq.new(side, na, na, 0, false, false, false)
    int n = cs.size()
    if n >= 2
        for back = 0 to 2
            int i2 = n - 1 - back
            if i2 >= 1 and not res.alive
                PoCandle c1 = cs.get(i2 - 1)
                PoCandle c2 = cs.get(i2)
                bool isLive = i2 == n - 1
                bool openInside = c2.o <= c1.h and c2.o >= c1.l
                bool hiSw = c2.h > c1.h
                bool loSw = c2.l < c1.l
                bool closedIn = c2.c < c1.h and c2.c > c1.l
                bool sweptThis = side == -1 ? hiSw : loSw
                bool sweptOther = side == -1 ? loSw : hiSw
                // v4: manipulation quality, C2 must run past C1 by a minimum share of the C1 range
                float c1r = c1.h - c1.l
                float swDepth = side == -1 ? c2.h - c1.h : c1.l - c2.l
                bool deepEnough = c1r > 0 and swDepth >= c1r * poC2MinSweep / 100.0
                // v4.4: "C2 must close inside C1" is a filter, not a hard rule -> honoured here too,
                // otherwise switching it off could never bring a reclaim-less sequence up.
                if openInside and sweptThis and deepEnough and (isLive or not poReqC2In or closedIn)
                    bool survives = true
                    if i2 < n - 1
                        for j = i2 + 1 to n - 1
                            PoCandle cj = cs.get(j)
                            if side == -1 and cj.h > c2.h
                                survives := false
                            if side == 1 and cj.l < c2.l
                                survives := false
                    // v4: failed distribution. C3 closed (not live) against the sequence = stop, no C4
                    if survives and poReqC3Dir and i2 < n - 2
                        PoCandle c3x = cs.get(i2 + 1)
                        survives := side == -1 ? c3x.c < c2.c : c3x.c > c2.c
                    if survives
                        res.i1 := i2 - 1
                        res.i2 := i2
                        res.phase := back + 2
                        res.closedIn := closedIn
                        res.twoSided := sweptOther
                        res.alive := true
    res

poSyncRecs(PoLane lane, PoSeq sq) =>
    int curC2 = na
    if sq.alive
        PoCandle c1 = lane.cs.get(sq.i1)
        PoCandle c2 = lane.cs.get(sq.i2)
        curC2 := c2.startBar
        int found = poFindRec(sq.side, c2.startBar)
        PoRec rc = na
        if found >= 0
            rc := poRecs.get(found)
        else
            rc := PoRec.new()
            rc.side := sq.side
            rc.maxPhase := 0
            rc.mcBar := array.new_int(3, na)
            rc.mcStart := array.new_int(3, na)
            rc.mcLvl := array.new_float(3, na)
            rc.alertCisd := false
            rc.alertC3 := false
            rc.alertC4 := false
            rc.cisdTried := false
            poRecs.push(rc)
            while poRecs.size() > 10
                poRecs.shift()
        rc.c1StartBar := c1.startBar
        rc.c1ExtBar := sq.side == -1 ? c1.hiBar : c1.loBar
        rc.c1Level := sq.side == -1 ? c1.h : c1.l
        rc.c1Hi := c1.h
        rc.c1Lo := c1.l
        rc.c2StartBar := c2.startBar
        rc.c2StartTime := c2.startTime
        rc.c2Open := c2.o
        rc.c2Wick := sq.side == -1 ? c2.h : c2.l
        rc.c2ExtBar := sq.side == -1 ? c2.hiBar : c2.loBar
        rc.twoSided := sq.twoSided
        rc.maxPhase := math.max(rc.maxPhase, sq.phase)
        rc.alive := true
        rc.c2Close := c2.c
        rc.c2Rng := c2.h - c2.l
        if not na(rc.cisdBar) and rc.cisdBar <= rc.c2ExtBar
            rc.cisdBar := na
            rc.cisdStartBar := na
            rc.cisdLevel := na
            rc.cisdTime := na
            rc.cisdBrokeT := na
        for k = 0 to 2
            int mb = rc.mcBar.get(k)
            if not na(mb) and mb <= rc.c2ExtBar
                rc.mcBar.set(k, na)
                rc.mcStart.set(k, na)
                rc.mcLvl.set(k, na)
        if sq.phase >= 3
            PoCandle c3 = lane.cs.get(sq.i2 + 1)
            rc.c3StartBar := c3.startBar
            rc.c3StartTime := c3.startTime
            rc.c3Open := c3.o
            rc.c3Wick := sq.side == -1 ? c3.h : c3.l
            rc.c3Close := c3.c
            rc.c3Rng := c3.h - c3.l
        if sq.phase >= 4
            PoCandle c4 = lane.cs.get(sq.i2 + 2)
            rc.c4StartTime := c4.startTime
        rc.psp := poPspFlag(c2)
    if poRecs.size() > 0
        for i = 0 to poRecs.size() - 1
            PoRec r1 = poRecs.get(i)
            if r1.side == sq.side
                bool nowAlive = sq.alive and r1.c2StartBar == curC2
                if r1.alive and not nowAlive
                    r1.endTime := time
                r1.alive := nowAlive
    lane

poScanSmtDir(PoLane ln, int no, bool qLane, int dir) =>
    int n = ln.cs.size()
    int found = 0
    array<float> usedLv = array.new_float(0)
    PoCandle cur = ln.cs.get(n - 1)
    int rFirst = n - 2
    int rLast = math.max(0, n - 1 - poSmtLookback)
    for r = rFirst to rLast
        PoCandle rf = ln.cs.get(r)
        if found < 2
            bool untouched = true
            if r < n - 2
                for j = r + 1 to n - 2
                    PoCandle mj = ln.cs.get(j)
                    if dir == -1 and mj.h >= rf.h
                        untouched := false
                    if dir == 1 and mj.l <= rf.l
                        untouched := false
            if untouched
                bool chartTook = dir == -1 ? cur.h > rf.h : cur.l < rf.l
                int valid = 0
                int diverging = 0
                string who = ""
                for k = 0 to 3
                    if poAOn.get(k) and rf.ok.get(k) and cur.ok.get(k)
                        valid += 1
                        bool inv = poAInv.get(k)
                        bool assetTook = false
                        if dir == -1
                            assetTook := inv ? cur.al.get(k) < rf.al.get(k) : cur.ah.get(k) > rf.ah.get(k)
                        else
                            assetTook := inv ? cur.ah.get(k) > rf.ah.get(k) : cur.al.get(k) < rf.al.get(k)
                        if assetTook != chartTook
                            diverging += 1
                            who := who + (str.length(who) > 0 ? "+" : "") + poALogos.get(k)
                bool diverged = valid > 0 and (poSmtAll ? diverging == valid : diverging > 0)
                float refLv = dir == -1 ? rf.h : rf.l
                if diverged and not poLevelUsed(usedLv, refLv)
                    found += 1
                    usedLv.push(refLv)
                    bool asSsmt = qLane and r == n - 2
                    poUpsertSmt(no, dir, rf.startBar, cur.startBar, refLv, dir == -1 ? cur.h : cur.l, dir == -1 ? rf.hiBar : rf.loBar, dir == -1 ? cur.hiBar : cur.loBar, who, asSsmt)
    found

poCleanSmt() =>
    int i = poSmtMarks.size() - 1
    while i >= 0
        PoSmt m = poSmtMarks.get(i)
        PoLane ln = poSmtLanes.get(m.lane - 1)
        int n = ln.cs.size()
        bool drop = false
        if n == 0 or not ln.active
            drop := true
        else
            PoCandle lastC = ln.cs.get(n - 1)
            int oldestStart = ln.cs.get(math.max(0, n - ln.count)).startBar
            bool live = m.curStart == lastC.startBar
            float hiEnd = math.max(m.refLevel, m.curLevel)
            float loEnd = math.min(m.refLevel, m.curLevel)
            if m.refStart < oldestStart
                drop := true
            else if live and m.seenBar != bar_index
                drop := true
            else if not live and m.dir == -1 and high > hiEnd
                drop := true
            else if not live and m.dir == 1 and low < loEnd
                drop := true
        if drop
            poSmtMarks.remove(i)
        i -= 1
    int nd = poSmtMarks.size()
    if nd > 1
        array<bool> dup = array.new_bool(nd, false)
        for a = 0 to nd - 1
            PoSmt ma = poSmtMarks.get(a)
            for b = 0 to nd - 1
                if b != a
                    PoSmt mb = poSmtMarks.get(b)
                    if mb.dir == ma.dir and mb.refBar == ma.refBar and mb.curBar == ma.curBar and (mb.lane > ma.lane or (mb.lane == ma.lane and mb.ssmt and not ma.ssmt))
                        dup.set(a, true)
        for a = nd - 1 to 0
            if dup.get(a)
                poSmtMarks.remove(a)
    array<int> cnt = array.new_int(16, 0)
    int k = poSmtMarks.size() - 1
    while k >= 0
        PoSmt mk = poSmtMarks.get(k)
        int slotK = mk.lane + (mk.ssmt ? 8 : 0)
        cnt.set(slotK, cnt.get(slotK) + 1)
        if cnt.get(slotK) > (mk.ssmt ? 2 : poSmtCycles)
            poSmtMarks.remove(k)

poSpotOk(PoRec rc) =>
    bool cisd = not na(rc.cisdBar)
    bool ok = true
    if poSpotStrict == "Easy"
        ok := cisd or rc.smt
    else if poSpotStrict == "Medium"
        ok := cisd and rc.smt
    else if poSpotStrict == "Hard"
        ok := cisd and rc.smt and rc.psp
    else if poSpotStrict == "Max"
        float rng = rc.c1Hi - rc.c1Lo
        float eq = (rc.c1Hi + rc.c1Lo) / 2.0
        bool strong = rc.side == 1 ? rc.c2Close > eq : rc.c2Close < eq
        float depth = rc.side == 1 ? rc.c1Lo - rc.c2Wick : rc.c2Wick - rc.c1Hi
        bool deep = rng > 0 and depth >= rng * 0.1
        ok := cisd and rc.smt and rc.psp and strong and deep and not rc.twoSided
    if ok and poReqC2In and rc.maxPhase >= 3 and not na(rc.c2Close)
        ok := rc.c2Close < rc.c1Hi and rc.c2Close > rc.c1Lo
    if ok and poReqC3Dir and rc.maxPhase >= 4 and not na(rc.c3Close) and not na(rc.c2Close)
        ok := rc.side == 1 ? rc.c3Close > rc.c2Close : rc.c3Close < rc.c2Close
    ok

    float e = (top + bot) / 2.0

    else if poOrdEntryMode == "Far edge"

// v4.6: close time (ms) of the HTF candle that contains time t, same NY anchor as the candle cutter
poBucketCloseOf(int t, string tf) =>
    float sec = timeframe.in_seconds(tf)
    int res = na
    if not na(sec) and not na(t)
        if poAnch and sec < 86400
            int lm  = timestamp("UTC", year(t, poTz), month(t, poTz), dayofmonth(t, poTz), hour(t, poTz), minute(t, poTz), 0)
            int off = lm - (t - t % 60000)
            int bk  = int(math.floor((lm - poAnchorH * 3600000) / (sec * 1000.0)))
            res := int(poAnchorH * 3600000.0 + (bk + 1) * sec * 1000.0) - off
        else
            res := t + int(sec * 1000)
    res

// v4.6: entry valid until = earlier of (signal + "Pending expires" bars) and the close of the phase candle
// the entry lives in (C3 entry: end of C3, C4 entry: end of C4, CISD before C3: end of C3).
poOrdValidUntil(PoRec rc, string kind) =>
    int secMs   = poSrcOk ? int(timeframe.in_seconds(poSrcLane.tf) * 1000) : 0
    int byBars  = time + int(timeframe.in_seconds() * 1000) * poOrdExpire
    int phaseEnd = na
    if poSrcOk
        if (kind == "C4" or rc.maxPhase >= 4) and not na(rc.c4StartTime)
            phaseEnd := poBucketCloseOf(rc.c4StartTime, poSrcLane.tf)
        else if rc.maxPhase >= 3 and not na(rc.c3StartTime)
            phaseEnd := poBucketCloseOf(rc.c3StartTime, poSrcLane.tf)
        else if not na(rc.c2StartTime)
            phaseEnd := poBucketCloseOf(rc.c2StartTime, poSrcLane.tf) + secMs
    na(phaseEnd) ? byBars : math.min(byBars, phaseEnd)

// How many live / finished (not cancelled) orders this sequence already has.
poOrdCount(int side, int c2Bar) =>

    if poTrades.size() > 0
        for i = 0 to poTrades.size() - 1
            PoTrade q = poTrades.get(i)
            if q.side == side and q.c2Bar == c2Bar and q.status != -2
                cnt += 1
    cnt

poMakeTrade(PoRec rc, string kind, float entry0) =>
    PoTrade t = na
    if poOrdOn and not na(entry0) and not na(rc.c2Wick) and not na(rc.c2Rng) and poOrdCount(rc.side, rc.c2StartBar) < poOrdMaxPer
        float slip  = poOrdSlip * syminfo.mintick
        // CISD is a market order: filled slightly worse. T-Spot orders are limits: no entry slip.
        float entry = kind == "CISD" ? entry0 + rc.side * slip : entry0
        float buf   = rc.c2Rng * poOrdSlBuf / 100.0 + slip
        float sl    = rc.side == 1 ? rc.c2Wick - buf : rc.c2Wick + buf
        float risk  = (entry - sl) * rc.side
        bool  riskOk = risk > syminfo.mintick * 2 and (poOrdMaxRiskPct <= 0 or risk <= entry * poOrdMaxRiskPct / 100.0)
        if riskOk
            float tp1 = entry + rc.side * risk * poOrdTp1Rr
            if poOrdTp1Mode == "C1 midpoint"
                float c1m = (rc.c1Hi + rc.c1Lo) / 2.0
                if (c1m - entry) * rc.side > risk * 0.5
                    tp1 := c1m
            else if poOrdTp1Mode == "C1 opposite extreme"
                float c1o = rc.side == 1 ? rc.c1Hi : rc.c1Lo
                if (c1o - entry) * rc.side > risk * 0.5
                    tp1 := c1o
            float tp2 = entry + rc.side * risk * poOrdTp2Rr
            // v4: full distribution = the far side of C1 (only when it lies beyond TP1)
            if poOrdTp2Mode == "C1 opposite extreme"
                float c1o2 = rc.side == 1 ? rc.c1Hi : rc.c1Lo
                if (c1o2 - tp1) * rc.side > 0
                    tp2 := c1o2
            if (tp2 - tp1) * rc.side <= 0
                tp2 := tp1 + rc.side * risk
            if (tp1 - entry) * rc.side >= risk * poOrdMinRr
                t := PoTrade.new(rc.side, kind, entry, sl, tp1, tp2, bar_index, time, na, na, na, na, 0, na, rc.c2StartBar, poOrdValidUntil(rc, kind))
                poTrades.push(t)
                while poTrades.size() > 300
                    poTrades.shift()
    t

poOrdStep() =>
    if poTrades.size() > 0
        for i = 0 to poTrades.size() - 1
            PoTrade t = poTrades.get(i)
            bool bull = t.side == 1
            if t.status == 0
                // CISD = market, Near edge = fills on the touch that fired the signal, deeper limits only from the next bar
                bool canFill = t.kind == "CISD" or poOrdEntryMode == "Near edge" or bar_index > t.sigBar
                bool touch   = bull ? low <= t.entry : high >= t.entry
                bool away    = bull ? high >= t.tp1 : low <= t.tp1
                bool stale   = bar_index - t.sigBar > poOrdExpire
                bool expired = not na(t.expT) and time >= t.expT   // v4.6: past the phase / expiry deadline
                bool slGone  = bull ? low <= t.sl : high >= t.sl
                bool recDead = true
                int  rIdx    = poFindRec(t.side, t.c2Bar)
                if rIdx >= 0
                    PoRec rq = poRecs.get(rIdx)
                    recDead := not rq.alive or (t.kind == "C3" and rq.spot3Dead) or (t.kind == "C4" and rq.spot4Dead)
                // v4.5 FIX A2: an order whose sequence / T-Spot is dead can no longer fill (before, the fill
                // won over the cancellation on the same bar). A CISD market order is filled on its own
                // signal bar, which is the bar it is created on, so it is never blocked by recDead there:
                // the order only exists because the sequence was alive when it was made.
                bool cisdNow = t.kind == "CISD" and t.sigBar == bar_index
                bool doFill  = canFill and touch and not expired and (cisdNow or not recDead)
                if doFill
                    t.status := 1
                    t.fillBar := bar_index
                    t.fillTime := time
                    // conservative: a T-Spot limit that fills and also reaches the SL on the same bar counts as SL
                    if t.kind != "CISD" and (bull ? low <= t.sl : high >= t.sl)
                        t.status := -1
                        t.endTime := time
                else if away or stale or slGone or recDead or expired
                    t.status := -2
                    t.endTime := time
            else if t.status == 1 and bar_index > t.fillBar
                bool slHit = bull ? low <= t.sl : high >= t.sl
                bool tp1Hit = bull ? high >= t.tp1 : low <= t.tp1
                bool tp2Hit = bull ? high >= t.tp2 : low <= t.tp2
                if slHit
                    t.status := -1
                    t.endTime := time
                else if tp2Hit
                    t.status := 3
                    t.endTime := time
                else if tp1Hit
                    t.status := 2
                    t.tp1Bar := bar_index
                    t.tp1Time := time
            else if t.status == 2 and bar_index > t.tp1Bar
                bool beHit = bull ? low <= t.entry : high >= t.entry
                bool tp2Hit2 = bull ? high >= t.tp2 : low <= t.tp2
                if beHit
                    t.status := 4
                    t.endTime := time
                else if tp2Hit2
                    t.status := 3
                    t.endTime := time
    0

// Stats over the stored orders (computed on demand, so nothing is double counted in realtime).
// Returns [closed, sl, be, tp2, tp1Hits, runners, open, netR]
poOrdStats() =>
    int   closedN = 0
    int   slN = 0
    int   beN = 0
    int   tp2N = 0
    int   tp1N = 0
    int   runN = 0
    int   openN = 0
    float netR = 0.0
    float p = poOrdPartial / 100.0
    if poTrades.size() > 0
        for i = 0 to poTrades.size() - 1
            PoTrade t = poTrades.get(i)
            float risk = math.abs(t.entry - t.sl)
            float rr1 = risk > 0 ? math.abs(t.tp1 - t.entry) / risk : 0.0
            float rr2 = risk > 0 ? math.abs(t.tp2 - t.entry) / risk : 0.0
            if t.status == 0 or t.status == 1 or t.status == 2
                openN += 1
            if t.status == 2
                runN += 1
                tp1N += 1
            else if t.status == -1
                closedN += 1
                slN += 1
                netR -= 1.0
            else if t.status == 4
                closedN += 1
                beN += 1
                tp1N += 1
                netR += p * rr1
            else if t.status == 3
                closedN += 1
                tp2N += 1
                tp1N += 1
                netR += p * rr1 + (1.0 - p) * rr2
    [closedN, slN, beN, tp2N, tp1N, runN, openN, netR]

// Fires once per record as soon as cisdBar exists and is fresh (<= 2 bars old), so 3m / 5m CISD

poAggStep(PoAgg g, bool isNew) =>
    int res = 0
    if isNew and g.has and (na(g.doneBar) or g.doneBar != bar_index)
        g.doneBar := bar_index
        int d = poDir(g.o, g.c)
        if d == -1
            if g.prevDir == -1
                g.bearLen += 1
            else
                g.bearLen := 1
                g.bearFirst := g.o
                g.bearBar := g.startBar
            g.bearLast := g.o
        if d == 1
            if g.prevDir == 1
                g.bullLen += 1
            else
                g.bullLen := 1
                g.bullFirst := g.o
                g.bullBar := g.startBar
            g.bullLast := g.o
        float bearLvl = poCisdSens == "Sensitive" ? g.bearLast : g.bearFirst
        float bullLvl = poCisdSens == "Sensitive" ? g.bullLast : g.bullFirst
        if d == 1 and not na(bearLvl) and g.bearLen >= poCisdMinRun and g.c > bearLvl and bar_index - g.bearBar <= 600
            res := 1
            g.hitLvl := bearLvl
            g.hitStart := g.bearBar
            g.bearFirst := na
            g.bearLast := na
            g.bearLen := 0
        else if d == -1 and not na(bullLvl) and g.bullLen >= poCisdMinRun and g.c < bullLvl and bar_index - g.bullBar <= 600
            res := -1
            g.hitLvl := bullLvl
            g.hitStart := g.bullBar
            g.bullFirst := na
            g.bullLast := na
            g.bullLen := 0
        g.prevDir := d
    if isNew
        g.o := open
        g.h := high
        g.l := low
        g.c := close
        g.startBar := bar_index
        g.has := true
    else if g.has
        g.h := math.max(g.h, high)
        g.l := math.min(g.l, low)
        g.c := close
    res

poAggLink(PoAgg g, int dir, int slot) =>
    if dir != 0 and poRecs.size() > 0

                poLinkCisd(rc, slot, bar_index - 1, g.hitStart, g.hitLvl, time[1])
    0

// ── Phase candle timer helpers (v4.2) ────────────────────────────────────────
// ms -> "mm:ss" or "h:mm:ss"
poFmtDur(int ms) =>
    int totalS = int(math.floor(math.max(ms, 0) / 1000.0))
    int hrs  = int(math.floor(totalS / 3600.0))
    int mins = int(math.floor((totalS % 3600) / 60.0))
    int secs = totalS % 60
    string mm = mins < 10 ? "0" + str.tostring(mins) : str.tostring(mins)
    string ss = secs < 10 ? "0" + str.tostring(secs) : str.tostring(secs)
    hrs > 0 ? str.tostring(hrs) + ":" + mm + ":" + ss : mm + ":" + ss

// Order that belongs to the live sequence (same side + same C2), not cancelled
poSeqOrder(PoRec rc) =>
    PoTrade res = na
    if not na(rc) and poTrades.size() > 0
        for i = 0 to poTrades.size() - 1
            PoTrade q = poTrades.get(i)
            if q.side == rc.side and q.c2Bar == rc.c2StartBar and q.status != -2
                res := q
    res

// Last finished order (history only, not a signal)
poLastClosed() =>
    PoTrade res = na
    int i = poTrades.size() - 1
    while i >= 0 and na(res)
        PoTrade q = poTrades.get(i)
        if q.status == 3 or q.status == 4 or q.status == -1
            res := q
        i -= 1
    res

// v4.7: newest ACTIVE order (pending / open / runner) from ANY sequence.
poActiveOrder() =>
    PoTrade res = na
    int i = poTrades.size() - 1
    while i >= 0 and na(res)
        PoTrade q = poTrades.get(i)
        if q.status >= 0 and q.status <= 2
            res := q
        i -= 1
    res

// Why the live sequence has no order yet
poWhyNoOrder(PoRec rc) =>
    string w = "no sequence"
    if not na(rc)
        if not poOrdOn
            w := "order entries off"
        else if rc.maxPhase < 3
            w := "waits C2 close (C3 open)"
        else if not poSpotOk(rc)
            string miss = ""
            if poSpotStrict == "Easy" and na(rc.cisdBar) and not rc.smt
                miss := " CISD/SMT"
            if poSpotStrict == "Medium" or poSpotStrict == "Hard" or poSpotStrict == "Max"
                if na(rc.cisdBar)
                    miss := miss + " CISD"
                if not rc.smt
                    miss := miss + " SMT"
            if (poSpotStrict == "Hard" or poSpotStrict == "Max") and not rc.psp
                miss := miss + " PSP"
            if poSpotStrict == "Max" and miss == ""
                miss := " Max rules"
            if poReqC2In and not na(rc.c2Close) and not (rc.c2Close < rc.c1Hi and rc.c2Close > rc.c1Lo)
                miss := miss + " C2-in-C1"
            w := "filter " + poSpotStrict + " needs:" + miss
        else if rc.cisdTried
            w := "CISD order skipped (risk % / min TP1 R)"
        else

    w

// v4.6: ENTRY NOW = a placed limit that is still waiting, or an entry taken within the last few bars.
// Returns the time until which the entry is actionable (na = not actionable).
poNowExpT(PoTrade od) =>
    int e = na
    if not na(od)
        int chartMs = int(timeframe.in_seconds() * 1000)
        if od.status == 0
            e := od.expT
        else if od.status == 1 and not na(od.fillTime) and bar_index - od.fillBar <= poNowBars
            e := od.fillTime + chartMs * (poNowBars + 1)
            if not na(od.expT)
                e := math.min(e, od.expT)
    e

poNowLeftMs(int e) =>
    int left = na
    if not na(e)
        int nowT = barstate.isrealtime ? timenow : math.min(timenow, na(time_close) ? timenow : time_close)
        left := math.max(e - nowT, 0)
    left

// ── Layout ───────────────────────────────────────────────────────────────────
type PoLayout
    array<int> starts
    int   slot
    int   bw
    int   gapEff
    int   cursor
    float rowTop
    float rowBot

poLayoutCalc() =>
    int activeLanes = 0
    int reservedTotal = 0
    for li = 0 to 2
        PoLane l0 = poLanes.get(li)
        if l0.active and l0.cs.size() > 0
            activeLanes += 1
            reservedTotal += l0.count
    int baseSlot = poCandleW * 2 + 1
    int slotCap = reservedTotal > 0 ? int(math.floor((485 - poRightOffset - math.max(activeLanes - 1, 0)) / reservedTotal)) : baseSlot
    int slot = math.max(2, math.min(baseSlot, slotCap))
    int bw = slot - 1
    int gapEff = poLaneGap
    if activeLanes > 1
        int room = 485 - poRightOffset - reservedTotal * slot
        gapEff := math.max(1, math.min(poLaneGap, int(math.floor(room / (activeLanes - 1)))))
    array<int> starts = array.new_int(3, -1)
    int cursor = poRightOffset
    for li = 0 to 2
        PoLane l1 = poLanes.get(li)
        if l1.active and l1.cs.size() > 0
            starts.set(li, cursor)
            cursor += l1.count * slot + gapEff

    float rowTop = na
    float rowBot = na
    for li = 0 to 2
        PoLane l2 = poLanes.get(li)
        if l2.active and starts.get(li) >= 0
            int n2 = l2.cs.size()
            int sh2 = math.min(l2.count, n2)
            for idx = n2 - sh2 to n2 - 1
                PoCandle cx = l2.cs.get(idx)
                rowTop := na(rowTop) ? cx.h : math.max(rowTop, cx.h)
                rowBot := na(rowBot) ? cx.l : math.min(rowBot, cx.l)

    PoLayout.new(starts, slot, bw, gapEff, cursor, rowTop, rowBot)

poRenderLanes(PoLayout L) =>
    array<int> starts = L.starts
    int   slot = L.slot
    int   bw = L.bw
    int   gapEff = L.gapEff
    float rowTop = L.rowTop
    float rowBot = L.rowBot
    if po3ShowCandles and not na(rowTop)
        for li = 0 to 2
            PoLane ln = poLanes.get(li)
            int st = starts.get(li)
            if ln.active and st >= 0
                int n = ln.cs.size()
                int sh = math.min(ln.count, n)
                bool isSrc = (li + 1) == poSrcNo and poSrcOk
                for idx = n - sh to n - 1
                    PoCandle cd = ln.cs.get(idx)
                    int lx = poCandleLeft(st, ln.count, n, idx, slot)
                    int rx = lx + bw
                    int mx = lx + int(bw / 2)
                    int cdir = poDir(cd.o, cd.c)
                    float top = math.max(cd.o, cd.c)
                    float bot = math.min(cd.o, cd.c)
                    if cdir == 0
                        top := top + syminfo.mintick * 0.5
                        bot := bot - syminfo.mintick * 0.5
                    color fillC = cdir == 1 ? poBullBody : cdir == -1 ? poBearBody : color.gray
                    color edgeC = cdir == 1 ? poBullBorder : poBearBorder
                    if po3ShowPsp and poPspOn and idx >= 1
                        PoCandle pv = ln.cs.get(idx - 1)
                        if (cd.h > pv.h or cd.l < pv.l) and poPspFlag(cd)
                            fillC := cdir == 1 ? poPspBull : poPspBear
                    poBoxI(lx, top, rx, bot, fillC, edgeC, 1)
                    poLineI(mx, cd.h, mx, top, poWick, line.style_solid, 1)
                    poLineI(mx, bot, mx, cd.l, poWick, line.style_solid, 1)
                    if poMidpoint and idx < n - 1
                        float mid = (cd.h + cd.l) / 2.0

                    if isSrc and poHOpen and idx < n - 1
                        poLineI(rx, cd.o, rx + 2, cd.o, poHOpenCol, line.style_dotted, 1)
                poDrawImbalances(ln, st, slot, bw)

                if isSrc and po3ShowProfile and poDisp.side != 0
                    bool abv = poDisp.side == -1
                    int remSrc = poSrcRemMs()
                    if poLabelMode != "Off"
                        int jMax = math.min(poDisp.i2 + (poLabelMode == "C1/C2/C3/C4" ? 2 : 1), n - 1)
                        for j = poDisp.i1 to jMax
                            if ln.count - n + j >= 0
                                PoCandle cj = ln.cs.get(j)
                                string tag = poPhaseTag(j == poDisp.i1 ? "C1" : j == poDisp.i2 ? (poDisp.twoSided ? "xC2" : "C2") : j == poDisp.i2 + 1 ? "C3" : "C4")
                                // v4.2: the live candle carries its countdown
                                if poPhaseTimer and j == n - 1 and not na(remSrc)
                                    tag := tag + "\n⏱ " + poFmtDur(remSrc)
                                int jx = poCandleLeft(st, ln.count, n, j, slot) + int(bw / 2)
                                poLabelI(jx, abv ? cj.h : cj.l, tag, abv ? label.style_label_down : label.style_label_up, j == poDisp.i1 ? poBadgeCol : poAccent, poSize(poCandleTxt))
                    if poSweepLine and ln.count - n + poDisp.i1 >= 0
                        PoCandle k1 = ln.cs.get(poDisp.i1)
                        float lv = poDisp.side == -1 ? k1.h : k1.l
                        int sx1 = poCandleLeft(st, ln.count, n, poDisp.i1, slot) + int(bw / 2)
                        int sx2 = poCandleLeft(st, ln.count, n, poDisp.i2, slot) + bw + 1
                        poLineI(sx1, lv, sx2, lv, poSweepCol, line.style_solid, 1)

                if poHlTimes and sh > 0
                    int hiIdx = n - sh
                    int loIdx = n - sh
                    for idx = n - sh to n - 1
                        if ln.cs.get(idx).h > ln.cs.get(hiIdx).h
                            hiIdx := idx
                        if ln.cs.get(idx).l < ln.cs.get(loIdx).l
                            loIdx := idx
                    bool srcTags = isSrc and po3ShowProfile and poDisp.side != 0 and poLabelMode != "Off"
                    int tagEnd = srcTags ? poDisp.i2 + (poLabelMode == "C1/C2/C3/C4" ? 2 : 1) : -1
                    bool hiTaken = srcTags and poDisp.side == -1 and hiIdx >= poDisp.i1 and hiIdx <= tagEnd
                    bool loTaken = srcTags and poDisp.side == 1 and loIdx >= poDisp.i1 and loIdx <= tagEnd

                    PoCandle clo = ln.cs.get(loIdx)
                    if not hiTaken
                        poLabelI(poCandleLeft(st, ln.count, n, hiIdx, slot) + int(bw / 2), chi.h, str.format_time(chi.startTime, "HH:mm", poTz), label.style_label_down, poBadgeCol, poSize(poChartTxt))
                    if not loTaken
                        poLabelI(poCandleLeft(st, ln.count, n, loIdx, slot) + int(bw / 2), clo.l, str.format_time(clo.startTime, "HH:mm", poTz), label.style_label_up, poBadgeCol, poSize(poChartTxt))

                if poBadge != "Off"
                    int bkL = li == 0 ? poBk1 : li == 1 ? poBk2 : poBk3
                    int cxm = bar_index + st + int(((ln.count - 1) * slot + bw) / 2.0)
                    string badge = poFmtTf(ln.tf)
                    float pctLeft = na
                    if poBadge == "Full"
                        string cdTxt = poCountdown(ln.tf, bkL)
                        if str.length(cdTxt) > 0
                            badge := badge + "\n(" + cdTxt + ")"
                    else if poBadge == "% left"
                        pctLeft := poPctLeft(ln.tf, bkL)
                        if not na(pctLeft)
                            badge := badge + "\n(" + str.tostring(math.round(pctLeft * 100)) + "%)"
                    // v4.2: the profile lane badge also names the live phase (C1 / C2 / C3 / C4)

                            if str.length(cdS) > 0
                                badge := badge + "\n(" + cdS + ")"
                    if isSrc
                        badge := "✦ " + badge
                    color bcol = isSrc ? poAccent : poBadgeCol
                    if not na(pctLeft) and pctLeft < 0.1

                    float padY = (rowTop - rowBot) * (poHlTimes ? 0.07 : 0.04)

                    if poBadgePos != "Top"
                        poLabelI(cxm, rowBot - padY, badge, label.style_label_up, bcol, poSize(poCandleTxt))

                if poDivider and li > 0
                    int dx = bar_index + st - int(gapEff / 2)
                    poLineI(dx, rowBot, dx, rowTop, color.new(color.gray, 55), line.style_dotted, 1)

        if po3ShowSmt and poSmtHtf and poSmtMarks.size() > 0
            for mi = 0 to poSmtMarks.size() - 1
                PoSmt sm = poSmtMarks.get(mi)
                PoLane sl = poSmtLanes.get(sm.lane - 1)
                for dl = 0 to 2
                    PoLane ml = poLanes.get(dl)
                    int stl = starts.get(dl)
                    if ml.active and stl >= 0 and poSameTf(ml.tf, sl.tf)
                        int nl = ml.cs.size()
                        int ir = poIdxByStart(ml, sm.refStart)
                        int ic = poIdxByStart(ml, sm.curStart)
                        if ir >= 0 and ic >= 0
                            int kr = ml.count - nl + ir
                            int kc = ml.count - nl + ic
                            if kr >= 0 and kc >= 0
                                int xr = bar_index + stl + kr * slot + int(bw / 2)
                                int xc = bar_index + stl + kc * slot + int(bw / 2)
                                poLineI(xr, sm.refLevel, xc, sm.curLevel, poSmtColor(sm), line.style_solid, 2)
    0

    array<int> starts = L.starts

    if po3ShowLevels and timeframe.isintraday

            poLabelT(keyEnd, poPdh, "PDH", label.style_label_left, poKeyPdCol, poSize(poChartTxt))

            float pdEq = (poPdh + poPdl) / 2.0

poRenderProfile() =>
    int chartMs = int(timeframe.in_seconds() * 1000)
    int tMax = time + chartMs * 400
    // v4.5 FIX C: close of the live profile candle from the NY-anchored bucket (same as the cutter),
    // not time_close(tf) which follows the exchange session clock.
    int bkSrc = poSrcNo == 1 ? poBk1 : poSrcNo == 2 ? poBk2 : poBk3
    [srcOpenT, srcCloseT] = poHtfSpan(poSrcLane.tf, bkSrc)
    int closeT = poSrcOk ? srcCloseT : na
    int liveEnd = na(closeT) ? time + chartMs * 20 : math.min(closeT, tMax)
    if po3ShowProfile and poSrcOk
        int drawnRec = 0
        bool stdvDone = false
        int ri = poRecs.size() - 1
        while ri >= 0 and drawnRec < 4
            PoRec rc = poRecs.get(ri)
            // v4.7: when poChartLiveOnly is on, only LIVE sequences are drawn (chart = dashboard).
            bool show = poRecVisible(rc) and (rc.maxPhase >= 3 or rc.alive) and bar_index - rc.c2StartBar < 4000 and (not poChartLiveOnly or rc.alive)
            if show
                bool withStdv = not stdvDone and not na(rc.cisdBar)
                poDrawRec(rc, liveEnd, tMax, withStdv)
                stdvDone := stdvDone or withStdv
                drawnRec += 1
            ri -= 1

    if po3ShowEFvg and poEFvgs.size() > 0
        for fi = 0 to poEFvgs.size() - 1
            PoFvg f = poEFvgs.get(fi)
            color fc = f.bull ? poEFvgBull : poEFvgBear
            box fb = box.new(f.t1, f.top, f.endT, f.bot, xloc = xloc.bar_time, bgcolor = fc, border_color = color.new(fc, 100), text = f.disp ? "FVG" : "T-Spot FVG", text_size = poSize(poChartTxt), text_color = color.new(fc, 0), text_halign = text.align_right, text_valign = text.align_center)
            poBoxes.push(fb)

    if po3ShowCisd and poCisdScope == "All" and poCisds.size() > 0
        for ci = 0 to poCisds.size() - 1
            PoCisd cz = poCisds.get(ci)
            poLineI(cz.startBar, cz.level, cz.confirmBar + 3, cz.level, cz.bull ? poCisdBull : poCisdBear, line.style_solid, 2)
    0

poRenderSmt() =>
    if po3ShowSmt and poSmtChart and poSmtMarks.size() > 0
        int nm = poSmtMarks.size()
        float rngS = math.max(poHi300 - poLo300, syminfo.mintick * 20)
        float rowH = rngS * 0.012
        for mi = 0 to nm - 1
            PoSmt sc = poSmtMarks.get(mi)
            if sc.refBar < sc.curBar
                poLineI(sc.refBar, sc.refLevel, sc.curBar, sc.curLevel, poSmtColor(sc), sc.ssmt ? line.style_dashed : line.style_solid, 1)
                if poSmtDots
                    poLabels.push(label.new(sc.refBar, sc.refLevel, "", xloc = xloc.bar_index, style = label.style_circle, color = poSmtDotCol, size = size.tiny))
                if po3ShowSmtLbl and poSmtLabels != "Off"
                    int rank = 0
                    float myEnd = sc.dir == -1 ? math.max(sc.refLevel, sc.curLevel) : math.min(sc.refLevel, sc.curLevel)
                    for mj = 0 to nm - 1
                        if mj != mi
                            PoSmt so = poSmtMarks.get(mj)
                            float otherEnd = so.dir == -1 ? math.max(so.refLevel, so.curLevel) : math.min(so.refLevel, so.curLevel)
                            bool shares = so.dir == sc.dir and so.refBar < so.curBar and sc.refBar < so.curBar and math.abs(otherEnd - myEnd) <= rngS * 0.12
                            if shares and (so.lane < sc.lane or (so.lane == sc.lane and mj < mi))
                                rank += 1
                    string tfTxt = (sc.ssmt ? "ssmt " : "") + poTfLogo(poSmtLanes.get(sc.lane - 1).tf)
                    string txt = poSmtLabels == "HTF" or str.length(sc.who) == 0 ? tfTxt : poSmtLabels == "Assets" ? sc.who : tfTxt + "/" + sc.who
                    int lx = int(math.round((sc.refBar + sc.curBar) / 2.0))
                    float ly = (sc.refLevel + sc.curLevel) / 2.0 + (sc.dir == -1 ? 1 : -1) * rowH * (1 + rank)
                    poLabelI(lx, ly, txt, sc.dir == -1 ? label.style_label_down : label.style_label_up, poSmtLabelCol, poSize(poChartTxt))
    0

poRenderOrders() =>
    int n = poTrades.size()
    if poOrdOn and n > 0
        int chartMs = int(timeframe.in_seconds() * 1000)
        int extBars = math.max(1, math.min(poOrdExtend, poRightOffset - 1))

        // 1) Markers on the candles for the newest orders: entry (BUY / SELL), TP1, TP2 / SL / BE exits
        int shownM = 0
        int mi = n - 1
        while mi >= 0 and shownM < poOrdMarks
            PoTrade m = poTrades.get(mi)
            // v4.7: hide finished / cancelled markers when poChartLiveOnly is on (chart = dashboard)
            if m.status != -2 and (not poChartLiveOnly or (m.status >= 0 and m.status <= 2))
                shownM += 1
                bool bullM = m.side == 1
                int xm = not na(m.fillTime) ? m.fillTime : m.sigTime
                string entTxt = (bullM ? "▲ BUY " : "▼ SELL ") + m.kind + (m.status == 0 ? " LIMIT" : "")
                poOrdMarker(xm, m.entry, entTxt, bullM ? label.style_label_up : label.style_label_down, bullM ? poOrdBuyCol : poOrdSellCol)
                string tpSty = bullM ? label.style_label_down : label.style_label_up
                string slSty = bullM ? label.style_label_up : label.style_label_down
                if not na(m.tp1Time)
                    poOrdMarker(m.tp1Time, m.tp1, "TP1 ✓", tpSty, poOrdTpCol)
                if m.status == 3 and not na(m.endTime)
                    poOrdMarker(m.endTime, m.tp2, "TP2 ✓", tpSty, poOrdTpCol)
                if m.status == -1 and not na(m.endTime)
                    poOrdMarker(m.endTime, m.sl, "SL ✗", slSty, poOrdSlCol)
                if m.status == 4 and not na(m.endTime)
                    poOrdMarker(m.endTime, m.entry, "BE", slSty, color.gray)
            mi -= 1

        // 2) Entry / SL / TP1 / TP2 levels for the newest orders
        int shown = 0
        int i = n - 1
        while i >= 0 and shown < poOrdKeep
            PoTrade t = poTrades.get(i)
            bool closed = t.status == 3 or t.status == 4 or t.status == -1
            // v4.7: finished orders are hidden when poChartLiveOnly is on
            bool skip = t.status == -2 or (closed and (poOrdHideClosed or poChartLiveOnly))
            if not skip
                shown += 1
                int x1 = not na(t.fillTime) ? t.fillTime : t.sigTime
                int pendEnd = t.status == 0 and not na(t.expT) ? math.min(t.expT, time + chartMs * math.max(extBars, poRightOffset - 1)) : time + chartMs * extBars
                int x2 = closed ? t.endTime + chartMs * 2 : pendEnd
                if x2 > x1
                    float risk = math.abs(t.entry - t.sl)
                    float rr1 = risk > 0 ? math.abs(t.tp1 - t.entry) / risk : 0.0
                    float rr2 = risk > 0 ? math.abs(t.tp2 - t.entry) / risk : 0.0
                    int dim = closed ? 55 : 0
                    color slC = color.new(poOrdSlCol, dim)
                    color tpC = color.new(poOrdTpCol, dim)
                    color enC = color.new(poOrdEntryCol, dim)
                    poBoxT(x1, math.max(t.entry, t.sl), x2, math.min(t.entry, t.sl), color.new(poOrdSlCol, closed ? 94 : 85), color.new(poOrdSlCol, 100), 1)
                    poBoxT(x1, math.max(t.entry, t.tp2), x2, math.min(t.entry, t.tp2), color.new(poOrdTpCol, closed ? 94 : 85), color.new(poOrdTpCol, 100), 1)
                    poLineT(x1, t.entry, x2, t.entry, enC, line.style_solid, 2)
                    poLineT(x1, t.sl, x2, t.sl, slC, line.style_solid, 2)
                    poLineT(x1, t.tp1, x2, t.tp1, tpC, line.style_dashed, 1)
                    poLineT(x1, t.tp2, x2, t.tp2, tpC, line.style_solid, 2)
                    poLabelT(x2, t.entry, "ENTRY " + str.tostring(t.entry, format.mintick) + "  [" + poOrdStatusTxt(t) + (t.status == 0 and not na(t.expT) ? " · exp " + str.format_time(t.expT, "HH:mm", poTz) : "") + "]", label.style_label_left, enC, poSize(poChartTxt))
                    poLabelT(x2, t.sl, "SL " + str.tostring(t.sl, format.mintick), label.style_label_left, slC, poSize(poChartTxt))
                    poLabelT(x2, t.tp1, "TP1 " + str.tostring(t.tp1, format.mintick) + " · " + str.tostring(rr1, "#.#") + "R", label.style_label_left, tpC, poSize(poChartTxt))
                    poLabelT(x2, t.tp2, "TP2 " + str.tostring(t.tp2, format.mintick) + " · " + str.tostring(rr2, "#.#") + "R", label.style_label_left, tpC, poSize(poChartTxt))
            i -= 1
    0
